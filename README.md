# Самостоятельное задание «Композиция компонентов» — Компонент Collapse

Практический мини-проект на React 19 + TypeScript 5, реализующий универсальный интерактивный контейнер «аккордеон» с динамической кастомизацией текстовых маркеров и плавной CSS-анимацией.

## 🚀 Архитектурные решения и оптимизации

- **Дефолтные параметры свойств (Props Defaulting):** Использование современных деструктурирующих присваиваний TypeScript на уровне аргументов функции (`collapsedLabel = 'Развернуть'`) обеспечивает автоматическую обработку пустых значений без написания избыточных условий `if` внутри JSX.
- **Оптимальная CSS-анимация (Max-Height Trick):** Полный отказ от использования JavaScript для вычисления динамических размеров элементов при открытии. Переключение состояния контролируется добавлением легкого класса `.show`, который запускает аппаратное ускорение рендеринга через свойства `max-height` и `opacity` со сглаживанием `ease-out`.
- **Композиция контента:** Компонент готов к инкапсуляции структуры любой сложности (от простого параграфа текста до интерактивных чекбоксов конфигураций) благодаря открытому паттерну `children`.

## 🛠️ Стек технологий

- React 19 (Хуки состояния `useState`)
- TypeScript 5 (Опциональные свойства интерфейсов)
- Vite 8
- Нативный CSS3 (Плавные переходы `transition` и изоляция переполнения контента через `overflow`)

## 🔧 Запуск проекта

1. Установка зависимостей:

   ```bash
   npm install
   ```

2. Запуск сервера разработки:

   ```bash
   npm run dev
   ```
